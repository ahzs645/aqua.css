# Recreation icons

32×32 System Preferences toolbar icons used by `recreations.html`, so the
recreations can be compared with real screenshots on the interface alone.
They are docs assets only: they are not referenced by the library CSS and are
not part of the npm package.

The artwork is Apple's, from Mac OS X 10.0–10.3, collected from:

| File | Source |
|---|---|
| `system-preferences-10-0.png` | "Mac OS X Puma Skin v2" XWindows Dock skin by iceler (DeviantArt), 128px icon scaled to 32px |
| `system-preferences-10-3.png` | [GUIdebook](https://guidebookgallery.org/icons/components), `settings/macosx103` |
| `displays.png` | GUIdebook, `settings/display/macosx100` |
| `sound.png` | GUIdebook, `settings/sound/macosx1028` |
| `network-10-2.png` | GUIdebook, `settings/network/macosx1028` (used for 10.0–10.2) |
| `network-10-3.png` | GUIdebook, `settings/internet/macosx1028` (used for 10.3) |
| `startup-disk.png` | [GUIdebook drives](https://guidebookgallery.org/icons/drivesdevices), `harddisk/macosx100` |

GUIdebook serves these flattened on white; the white matte was removed by
flood-filling from the edges, so white areas inside each icon are kept.
